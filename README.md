# 🧠 Life-OS Wellbeing Dashboard

An AI-powered digital wellbeing dashboard built using Streamlit and Gemini API.

## 🚀 Live Demo

🔗 **Deployed App:** [https://your-app-name.streamlit.app](https://life-os-dashboard-petwjdmpqqjfnyjzjbznpj.streamlit.app/)

## Features

- 📊 14-Day Screen Time Analytics
- 📈 Line Chart Trends
- 📊 Category Usage Visualization
- 🎯 Daily Goal Tracking
- 🤖 AI Lifestyle Coach (Gemini)
- 🎭 Dynamic Productivity Avatar
- 📥 Download Daily Report

## Tech Stack

- Python
- Streamlit
- Pandas
- Google Gemini API
- Python-dotenv

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```

## Dataset

Synthetic 14-day screen time dataset.
